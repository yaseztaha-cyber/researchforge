# Curated demo questions (each exercises a different capability)

1. Scientific evidence: "How does ocean acidification affect coral calcification?"
2. Engineering: "What are the structural risks of aging concrete bridges?"
3. Environmental: "What are the environmental impacts of desalination?"
4. Conflicting evidence: "How does brine discharge affect marine ecosystems?"
   (fixtures contain near-field vs far-field disagreement → conflict panel)
5. Hybrid (PDF + web): upload any methods-heavy PDF, then ask a question it
   covers in `hybrid` mode → check `uploaded` vs `web` origin badges and the
   claim inspector's page/section references.

Run 3 first in mock mode (works offline); 5 needs one real or sample PDF.
